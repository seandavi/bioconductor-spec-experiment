# ranges_e2

Experiment E2: IRanges / GRanges in Python, built **against a language-neutral
conformance suite whose expected outputs are generated by R**.

- Scope and done criteria: `../../TARGET.md`. Plan: [PLAN.md](PLAN.md). Decisions and costs: [NOTES.md](NOTES.md).
- R 4.6 / IRanges 2.47.2 / GenomicRanges 1.65.1 are normative. Python must match, or the case is
  listed in [`conformance/xfail.json`](conformance/xfail.json) with a reason.
- Current state: **921 cases, 155 clauses.** R check 921/921. Python 917 pass, 4 xfail, 0 fail.
  `uv run pytest`: 2037 passed, 4 xfailed. Details: [conformance/REPORT.md](conformance/REPORT.md).

## Quick start

```sh
uv run pytest                                   # everything (suite + unit tests)
just check-r                                    # Rscript: R vs stored goldens (drift detector)
just check-py                                   # Python vs goldens, writes reports/python.json
just report                                     # both checks, then rebuild conformance/REPORT.md
just types                                      # mypy --strict
just fuzz --seed 3 --n 3000                     # random R-vs-Python differential run (throw-away cases)
```

## Layout

```
conformance/                 language-neutral; readable without Python or R
  FORMAT.md                  serialization spec (normative for both codecs)
  cases/<group>.json         AUTHORED: clauses, fixtures, cases (no outputs)
  expected/<group>.json      GENERATED by R. Never hand-edit.
  xfail.json                 {case_id: reason} cases Python should not pass
  r/codec.R r/run.R          R encode/decode, runner (validate | generate | check)
  reports/{r,python}.json    per-case status; REPORT.md is built from them
src/ranges_e2/               the library
  iranges.py granges.py seqinfo.py hits.py rle.py     public classes
  _inter _intra _overlaps _nearest _ordering _coverage _mcols _util   array kernels
  conformance/               harness: codec.py ops.py runner.py report.py
tests/                       test_conformance (every case) test_codec test_comparator test_api test_kernels
```

Rule: the library never imports `conformance/`. The harness depends on the library.

## How the suite works

1. A **case** = `op` (an R function name), `args`/`kwargs` (R argument names), one **clause** id.
   A **clause** = one sentence of observable behavior. Every case names exactly one clause; every
   clause has at least one case (both runners enforce this, plus unique ids and resolvable refs).
2. `Rscript conformance/r/run.R generate <group>` runs each case with `do.call(op, ...)`, encodes
   the result (or the error) with the R codec and writes `expected/<group>.json`.
3. Python decodes the same inputs, calls the op through `conformance/ops.py`, encodes its own
   result and compares the two **JSON trees**. Errors pass if Python raises
   `ValueError/TypeError/IndexError/KeyError`; messages and warnings are not compared.
4. The R runner's `check` re-runs R against the goldens, so an R/Bioc upgrade shows up as drift.

### Format in one screen (full spec: FORMAT.md)

- Atomic vectors are tagged so int/double/NA survive: `{"$int":[1,null]}`, `$dbl`, `$chr`, `$lgl`; optional `names`.
- Objects are `{"$type": ...}`: `IRanges`, `GRanges`, `Seqinfo`, `DFrame` (mcols), `Hits`, `Rle`,
  `RleList`, `IntegerList` (revmap), `Factor`. Key order is significant.
- All indices in the files are **1-based** (R). Only `conformance/ops.py` converts.
- Compare modes: `exact`, and `hits-query-grouped` (query order exact, subject order within a query
  free) for `findOverlaps`/`nearest`, where R's within-query order is an NCList artifact.

## Python API

Immutable classes; methods return new objects. Arrays handed out by accessors are read-only and `mcols` frames are private copies, so nothing a caller holds can change an object. Coordinates are 1-based closed (as R).
**Indices are 0-based; `NA_INDEX = -1` marks "no hit"** (select outputs, GRanges `distance`).
`rank()` values are R ranks (1..n). `mcols` are polars DataFrames; "no columns" is stored as `None`
(polars cannot hold 0 columns with rows), and `x.mcols` then returns an empty frame.

| R | Python |
|---|---|
| `IRanges(start, end, width, names)` | `IRanges(start=, end=, width=, names=, mcols=)` (positional 2nd arg is `end`, as R) |
| `GRanges(seqnames, ranges, strand, ..., seqinfo, seqlengths)` | `GRanges(seqnames, ranges, strand, *, seqinfo=, seqlengths=, mcols=, **columns)` |
| `start end width names length mcols` | `.start .end .width .names len() .mcols` |
| `seqnames strand ranges seqinfo seqlevels seqlengths isCircular genome` | `.seqnames .strand .ranges .seqinfo .seqlevels .seqlengths .is_circular .genome` |
| `x[i]`, `c(x, y)` | `x[i]` (int / slice / bool mask / names), `x.concat(y, ...)` |
| `shift narrow resize flank promoters trim` | same names; `resize(width, fix, use_names, ignore_strand)` |
| `range reduce gaps disjoin` | `.range() .reduce(drop_empty_ranges, min_gapwidth, with_revmap) .gaps(start, end) .disjoin(with_revmap)` |
| `union intersect setdiff punion pintersect psetdiff` | same names (`fill_gap`, `resolve_empty`) |
| `findOverlaps countOverlaps overlapsAny subsetByOverlaps` | `.find_overlaps(subject, maxgap, minoverlap, type, select) .count_overlaps .overlaps_any .subset_by_overlaps` |
| `nearest precede follow distance` | same names, `select=`, `subject=None` means self |
| `coverage` | `.coverage(shift, width, weight)` -> `Rle` (IRanges) or `{seqlevel: Rle}` (GRanges) |
| `order sort rank duplicated unique` | `.order .sort .rank(ties_method) .duplicated(from_last) .unique` |

GRanges methods take `ignore_strand=` wherever R does. Seqinfo: `Seqinfo(...)`, `.merge`, `.subset`,
`.with_field`, `.rename_levels`.

## Maintaining the suite

| Task | Steps |
|---|---|
| **Add behavior** | Add a clause (one sentence) + cases to `cases/<group>.json` -> `just generate <group>` -> read the new goldens for surprises -> commit cases and `expected/` together -> make Python pass. |
| **R / Bioc upgrade** | `just check-r` lists drifted cases -> review the diff -> `just generate` -> commit naming the upstream change -> `just check-py` now fails on exactly those cases. |
| **New op** | Add an `@op("name", <R params>)` adapter in `conformance/ops.py`. Unknown R arguments must raise `TypeError`. |
| **Hunt for new behavior** | `just fuzz --seed N --n 3000` generates random cases, has R produce goldens in a temp dir, runs Python, prints divergences. Promote each real finding to a named clause + cases in `cases/` (this is how `GR.SETOPS.CLIP`, `IR.REDUCE.DROPEMPTY` and `GR.NEAREST.TIE` were found). |
| **R quirk Python should not copy** | Add the case id and reason to `xfail.json` and a NOTES entry. xfails are strict: an unexpected pass fails the run. Review them on every upgrade. |
| **Unordered output** | Only when R's order is not a contract: set `"compare"` on the case or file and record why in NOTES. |

Never hand-edit `expected/`. Never edit a clause statement without regenerating its cases. Do not pin
unspecified behavior (e.g. `select="arbitrary"` with ties): two cases were removed for that.

## Known limits

- `nearest/precede/follow` are O(queries x subjects) (per-query numpy scan); overlaps are sorted-search.
- Warnings are recorded in goldens but not compared; Python does not emit R's warnings.
- `select="arbitrary"` returns the lowest subject index; the suite only pins unambiguous queries.
- Any `IntegerRanges` subclass (e.g. `NormalIRanges`) encodes as `IRanges`; no Views/Lists (out of scope).
- Cases whose behavior depends on R's locale are avoided (sorting of seqlevel names never happens in R here).
- **GRanges `precede/follow/nearest` with a range whose start or end is <= 0** (including a zero-width
  range at position 1, whose end is 0) can differ from R. R maps all sequences onto one number line
  (`offset + position`) with sentinels at the offsets, so positions <= 0 collide with a sentinel or
  leak into the previous sequence. ranges_e2 implements the documented semantics instead of cloning that.
  Random runs with starts >= 1 (~15k cases, all ops) find no other divergence apart from the xfail quirk.
- `GRanges.precede/follow` `select="first"/"last"` pick the lowest/highest subject index; R picks the first/last
  *hit* (plus-strand subjects before minus-strand ones for a `*` query), which differs only on exact ties across strands.

## Where serialization was hard (cost in NOTES.md)

R/Python **type mismatch**: JSON has no NA, ints vs doubles, empty vectors, or named vectors, so
every vector is tagged and Python carries a `Vec(kind, values, names)` for R-typed arguments.
Then: polars 0-column frames, `revmap` as a 0-based list column <-> 1-based `IntegerList`,
`Rle` of `factor` (`seqnames()`), and R's hit order. Authoring the 882 cases and reading the
goldens cost far more than either codec.
