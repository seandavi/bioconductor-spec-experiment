# PLAN — E2: conformance suite first

R is normative. Build a language-neutral conformance suite (cases as data,
R-generated goldens, R and Python runners), then implement `ranges_e2`
until it passes the suite.

Probed on this machine: R 4.6.0, IRanges 2.47.2, GenomicRanges 1.65.1,
S4Vectors 0.51.6, Seqinfo 1.3.0, jsonlite + yaml + testthat present.

## 1. Layout

```
experiments/e2-conformance/
  PLAN.md  NOTES.md  README.md  pyproject.toml  uv.lock
  conformance/                 # language-neutral; no Python or R imports needed to read
    FORMAT.md                  # serialization spec (normative for both codecs)
    cases/<group>.json         # authored: clauses, fixtures, cases (no outputs)
    expected/<group>.json      # generated by R. Never hand-edit.
    xfail.json                 # {case_id: reason} cases Python should not/cannot pass
    r/codec.R                  # R encode/decode
    r/run.R                    # Rscript conformance/r/run.R generate|check [group...]
    reports/r.json             # per-case status from R check
    reports/python.json        # per-case status from Python runner
    REPORT.md                  # generated: pass/fail per clause per implementation
  src/ranges_e2/
    __init__.py                # public exports
    _vec.py                    # int32 range kernels shared by IRanges/GRanges (no classes)
    iranges.py                 # IRanges: construction, accessors, [], c, mcols
    _intra.py                  # shift narrow resize flank promoters (array kernels)
    _inter.py                  # range reduce gaps disjoin (sort + sweep)
    _setops.py                 # union intersect setdiff + p* versions
    _overlaps.py               # find/count/overlapsAny/subsetByOverlaps -> Hits
    _nearest.py                # nearest precede follow distance
    _ordering.py               # order sort rank duplicated unique
    rle.py                     # minimal Rle (values, lengths) for coverage
    hits.py                    # Hits
    seqinfo.py                 # Seqinfo + merge
    granges.py                 # GRanges; strand-aware ops via one grouping helper
    conformance/
      codec.py                 # JSON tree <-> ranges_e2 objects
      ops.py                   # op table: R op name -> Python adapter
      runner.py                # load cases+expected, run, compare, write report
      report.py                # reports/*.json -> REPORT.md
  tests/
    test_codec.py              # decode(expected) -> encode == expected, for every golden
    test_conformance.py        # pytest parametrized over every case; xfail.json -> strict xfail
    test_*.py                  # small unit tests only where the suite can't reach
```

Rule: core modules never import `conformance/`. The codec depends on the core,
not the reverse.

## 2. Serialization format (`conformance/FORMAT.md`)

JSON. Both sides parse without type simplification (R: `jsonlite::fromJSON(simplifyVector = FALSE)`;
Python: `json`). JSON `null` = R `NA`. All indices in the format are
**1-based** (R-native); the Python adapter layer converts.

### Atomic vectors — always tagged in canonical (R-written) output

| Tag | R type | Example |
|---|---|---|
| `{"$int": [...]}` | integer | `{"$int": [1, null]}` |
| `{"$dbl": [...]}` | double | `{"$dbl": [1.5, null]}` (`"NaN"`, `"Inf"`, `"-Inf"` as strings) |
| `{"$chr": [...]}` | character | |
| `{"$lgl": [...]}` | logical | |

Optional `"names": [...]` key on any tagged vector.

**Authoring shorthand (inputs only):** bare JSON scalars/arrays. Integer literal
→ integer, literal with `.`/exponent → double, string → character, bool →
logical. Both parsers distinguish `1` from `1.0` (verified for jsonlite).
Expected outputs are always fully tagged.

### Objects (`"$type"`)

| `$type` | Fields (canonical) | Notes |
|---|---|---|
| `IRanges` | `start` `$int`, `width` `$int`, `names` `$chr`\|null, `mcols` DFrame | Inputs may give any two of start/end/width. Any IntegerRanges subclass (NormalIRanges, …) encodes as IRanges. |
| `GRanges` | `seqnames` `$chr`, `start`, `width`, `strand` `$chr` (`+ - *`), `names`, `mcols`, `seqinfo` | seqnames level order lives in seqinfo |
| `Seqinfo` | `seqnames` `$chr`, `seqlengths` `$int`, `isCircular` `$lgl`, `genome` `$chr` | NA → null |
| `DFrame` | `nrow` int, `columns` {name: value} | Object key order is significant. `mcols(x) == NULL` encodes as DFrame with `columns: {}`. |
| `Hits` | `from` `$int`, `to` `$int`, `nLnode`, `nRnode` | 1-based. Any Hits subclass. Order as R emits it. |
| `Rle` | `values` (tagged), `lengths` `$int` | |
| `RleList` | `elements` {name: Rle} | GRanges `coverage` output only |
| `IntegerList` | `elements` [[int,…],…], `names` | `revmap` column; 1-based |
| `Factor` | `levels` `$chr`, `codes` `$int` | only if an op returns a factor |

### Errors and warnings

Expected entry for a case is one of:

```json
{"value": <encoded result>, "warnings": ["..."]}
{"error": {"message": "...", "class": ["simpleError", "error", "condition"]}}
```

- Error case passes in Python if the adapter raises `ValueError`, `TypeError`,
  `IndexError` or `KeyError`. Messages are not compared.
- Warnings are recorded, not compared (v1). Python may warn freely.

### Comparison

Deep equality of encoded JSON trees, both sides encoding their own result.
Doubles: `abs(a-b) <= 1e-9 * max(1, abs(b))`. Per-case `"compare"` override:

| Mode | Meaning |
|---|---|
| `exact` (default) | tree equality |
| `hits-unordered` | Hits compared as a set of (from, to) pairs; nLnode/nRnode exact |

Add a mode only when a clause genuinely leaves order unspecified; record why in NOTES.

## 3. Case files

`conformance/cases/<group>.json`:

```json
{
  "group": "iranges-inter",
  "clauses": {
    "IR.REDUCE.MINGAP": "reduce merges ranges separated by gaps < min.gapwidth",
    "IR.REDUCE.REVMAP": "with.revmap adds mcols$revmap: IntegerList of input indices per output range"
  },
  "fixtures": {
    "x": {"$type": "IRanges", "start": [1, 5, 12], "width": [3, 4, 0]}
  },
  "cases": [
    {"id": "ir.reduce.mingap2", "clause": "IR.REDUCE.MINGAP",
     "op": "reduce", "args": [{"$ref": "x"}], "kwargs": {"min.gapwidth": 2}}
  ]
}
```

- `op` is the R function name, called as `do.call(op, c(args, kwargs))` with
  `GenomicRanges` attached. Pseudo-ops for non-function syntax: `"["` (subset),
  `"c"`, `"names"`, `"mcols"`, `"length"`, constructors `"IRanges"`, `"GRanges"`, `"Seqinfo"`.
- `kwargs` keys use R names (`min.gapwidth`). The Python adapter maps them.
- `{"$ref": "name"}` resolves to a file-level fixture.
- Every case names exactly one clause; every clause has ≥1 case. Validator
  (in both runners) enforces this plus unique ids across all groups.
- Clause IDs: `IR.*` (IRanges), `GR.*` (GRanges), `SI.*` (Seqinfo). Statement
  is one sentence of observable behavior, written before generating goldens.

Planned groups (target ~250–350 cases total):

| Group | Covers |
|---|---|
| `iranges-core` | construct (any two of start/end/width), zero-width, names, accessors, `[` int/lgl/names, `c`, mcols, errors (negative width) |
| `iranges-intra` | shift narrow resize(fix) flank(start, both) promoters |
| `iranges-inter` | range reduce(min.gapwidth, drop.empty.ranges, with.revmap) gaps(start,end) disjoin |
| `iranges-setops` | union intersect setdiff punion pintersect psetdiff |
| `iranges-overlaps` | findOverlaps type × maxgap × minoverlap × select; countOverlaps overlapsAny subsetByOverlaps; zero-width query/subject |
| `iranges-nearest` | nearest precede follow (select first/all), distance, ties, empty subject |
| `iranges-coverage` | coverage (shift, width, weight int/dbl) |
| `iranges-order` | order sort(decreasing) rank(ties.method) duplicated unique |
| `seqinfo` | construction, seqlevels seqlengths isCircular genome, merge on `c`, incompatible merge error |
| `granges-core` | construct, accessors, `[`, `c`, mcols, trim, out-of-bound warning |
| `granges-intra` | strand-aware shift/resize/flank/promoters, circular seqs |
| `granges-inter` | range reduce gaps disjoin per seqname×strand, ignore.strand |
| `granges-setops` | set ops + p* with strand compatibility, ignore.strand |
| `granges-overlaps` | strand-compatible overlaps (`*` matches both), ignore.strand, cross-seqname |
| `granges-nearest` | strand-aware nearest/precede/follow/distance, NA across seqnames |
| `granges-coverage` | coverage → RleList over seqlevels, uses seqlengths |
| `granges-order` | order across seqlevels then strand (+ - *) then start then end |

## 4. Runners and reports

**R** `Rscript conformance/r/run.R generate [group...]`
- Loads cases, decodes args, runs each in `withCallingHandlers`/`tryCatch`,
  encodes result, writes `expected/<group>.json` with a `meta` block
  (R + package versions, timestamp). Pretty-printed, stable key order.
- Suppress package startup messages/"built under" warnings (seen on this machine).

**R** `Rscript conformance/r/run.R check`
- Re-runs every case, compares to `expected/`, writes `reports/r.json`.
  Exit nonzero on mismatch. This is the drift detector for R/Bioc upgrades.
- Also run an R codec roundtrip (`decode(encode(v))` identical to `v`) over all
  expected values.

**Python** `uv run python -m ranges_e2.conformance.runner [--report conformance/reports/python.json]`
- Same load/validate/compare logic; statuses `pass | fail | error | xfail | xpass`.
- `tests/test_conformance.py` parametrizes the same runner over every case
  (`uv run pytest` is the gate). `xfail.json` entries become strict xfail.

**Report** `uv run python -m ranges_e2.conformance.report` → `conformance/REPORT.md`:
per group and clause, pass counts for R and Python; list of xfails with reasons.

## 5. Python data model

| Class | Storage | Notes |
|---|---|---|
| `IRanges` | `start`, `width`: `np.ndarray[int32]`; `names`: `list[str] \| None`; `mcols`: `pl.DataFrame \| None` | `end` derived. Immutable; ops return new objects. int32 matches R; overflow → `ValueError` |
| `Seqinfo` | frozen dataclass of tuples: `seqnames`, `seqlengths` (int\|None), `is_circular` (bool\|None), `genome` (str\|None) | `merge()` per R rules |
| `GRanges` | `seqnames`: int32 codes into seqinfo; `ranges`: IRanges; `strand`: int8 codes 0 `+`, 1 `-`, 2 `*` (R level order); `seqinfo` | names/mcols live on the inner IRanges |
| `Hits` | `query_hits`, `subject_hits` (0-based int arrays), `query_length`, `subject_length` | |
| `Rle` | `values`, `lengths` arrays | internal + coverage output |

- Coordinates stay 1-based closed (genomic convention, matches TARGET).
- **Indices are 0-based in the Python API** (subsetting, Hits, order,
  revmap, select="first"). Ranks from `rank()` are R values (1..n).
  `ops.py` converts at the boundary, per op, explicitly.
- mcols: polars `DataFrame` (typed nulls, `List(Int32)` for revmap).
  Polars cannot hold 0 columns with height > 0 → `None` means "no columns";
  the `mcols` property returns an empty-column frame via a helper.
- API: snake_case methods on the classes (`x.reduce(min_gapwidth=1, drop_empty_ranges=False, with_revmap=False)`,
  `q.find_overlaps(s, type="any", maxgap=-1, minoverlap=0, select="all")`,
  `x.punion(y)`). Same method names on IRanges and GRanges; GRanges adds `ignore_strand`.
  Free-function aliases only if cheap; one spelling per concept.

## 6. Core algorithms

- **Kernels on arrays, classes thin.** `_inter`, `_overlaps`, etc. take
  `(start, width)` arrays and return arrays/index vectors. IRanges calls them
  once; GRanges calls them per group.
- **GRanges seam:** one helper `_by_group(gr, ignore_strand) -> iterable of (seq_code, strand_code, idx)`.
  Every strand-aware op = group → kernel → reassemble in R's output order
  (seqlevel, then strand + - *, then position). Getting this order right once
  fixes most GRanges cases.
- **reduce/gaps/disjoin:** sort by (start, end), linear sweep with numpy
  cumulative max of end. revmap = group membership indices.
- **findOverlaps:** sort subject by start; cumulative max of end over sorted
  order is monotone, so candidates for each query are a contiguous slice found
  by two `searchsorted` calls; filter exactly by type/maxgap/minoverlap.
  Output sorted by (query, subject) to match R's `SortedByQueryHits`.
  Note (probed): a zero-width query at 5 hits subject [2,11] under defaults —
  zero-width semantics need their own clauses.
- **nearest/precede/follow:** per R docs: overlap wins (distance 0) for
  `nearest`; ties → `select`. Use sorted starts/ends + searchsorted.
- **coverage:** +w at start, −w at end+1, sort events, cumulate → Rle; `width`
  defaults to max end.
- **ordering:** `np.lexsort` with stable sort; GRanges keys
  (seqname code, strand code, start, end).

## 7. Work breakdown (one commit per line unless noted)

**Phase A — suite (no Python implementation yet)**
1. `FORMAT.md` (from §2) + `r/codec.R` encode/decode + R roundtrip self-test on hand fixtures.
2. `r/run.R` generate/check + validator; `cases/iranges-core.json`; generate goldens. Commit cases + expected together.
3. One commit per remaining group in §3 order. For each: write clauses → write cases → `generate` → read the goldens for surprises → record surprises in NOTES → commit.
4. `check` passes for all groups; commit `reports/r.json`.

**Phase B — Python harness**
5. `conformance/codec.py` + `tests/test_codec.py` (decode→encode reproduces every golden byte-for-tree). This needs minimal class shells only (constructors + fields); stub ops raise `NotImplementedError`.
6. `ops.py`, `runner.py`, `tests/test_conformance.py`. Not-implemented cases fail; to keep `uv run pytest` usable during Phase C, gate with `-m conformance` or accept red until done (implementer's call; record in NOTES).

**Phase C — implementation** (commit per row; NOTES records pass count after each)
7. IRanges core → 8. intra → 9. inter → 10. setops → 11. overlaps →
12. nearest/distance → 13. coverage → 14. ordering →
15. Seqinfo → 16. GRanges core/trim/c → 17. GRanges intra →
18. GRanges inter + setops → 19. GRanges overlaps/nearest → 20. GRanges coverage/ordering.

**Phase D — close-out**
21. Triage remaining failures: fix, or add to `xfail.json` with reason + NOTES entry.
22. `report.py` → `REPORT.md`; both runners green.
23. README: design, format, how to add a case, how to handle an R upgrade.

## 8. Maintenance (goes in README)

- **Add behavior:** add clause + cases → `Rscript conformance/r/run.R generate <group>` → commit cases + expected → make Python pass.
- **R/Bioc upgrade:** `run.R check` lists drifted cases → review diff → `generate` → commit with message naming the upstream change → Python suite now fails on exactly those cases.
- **Never** hand-edit `expected/`. Never edit a clause statement without regenerating its cases.
- `xfail.json` entries need a reason and a NOTES entry; review them on every upgrade.

## 9. Risks

| Risk | Mitigation |
|---|---|
| Codec cost dominates (two codecs × ~10 types; GRanges seqinfo, mcols, revmap IntegerList, RleList). Expected to be the hard part. | Build R codec first, roundtrip-test it; Python codec validated against every golden before any op work. Log hours spent in NOTES (`serialization:` prefix). |
| int vs double ambiguity in JSON | Tagged canonical output; shorthand only in authored inputs; both parsers keep `1` vs `1.0`. |
| 0- vs 1-based index conversion bugs | Format is 1-based; conversion only in `ops.py`, declared per op. |
| Op dispatch mismatch (R S4 generics vs Python methods; R arg names) | Explicit op table; unknown kwargs → error, not silent drop. |
| `select="arbitrary"` not deterministic by contract | Pin only unambiguous queries; clause says so. |
| Hits order unspecified in docs | Default `exact`; use `hits-unordered` only with a NOTES entry. |
| GRanges output order (seqlevel × strand) for reduce/gaps/disjoin | Single `_by_group` helper; dedicated clauses. |
| `gaps` on GRanges emits gaps for all three strands and uses seqlengths | Dedicated clauses incl. NA seqlength. |
| Zero-width overlap semantics | Dedicated clauses (probed: zero-width inside a range counts as overlap). |
| Warnings (out-of-bound GRanges) | Recorded, not compared; clause notes it. |
| polars 0-column frames | `None` sentinel + helper. |
| 4-hour ceiling | Phase A capped ~1.5 h; if over, cut case count per group, not groups. |
