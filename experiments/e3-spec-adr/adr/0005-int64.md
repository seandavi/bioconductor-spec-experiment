# ADR-0005 int64 coordinates, no int32 overflow emulation

Status: accepted · Clauses: CONV.7

## Context
R IRanges uses 32-bit ints and errors on overflow.

## Decision
int64 everywhere. Results beyond int32 range are valid in Python and are
not refused. Not emulating R's overflow errors keeps kernels plain numpy.

## Consequences
Differs from R only for inputs near ±2^31; out of scope for the target.
