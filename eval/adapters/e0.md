# Adapter e0: unsupported ops and convention translations

Port: `ranges_e0` (frozen/e0-control). Index base: 0-based; `NO_MATCH == -1`. Docs used: its README and docstrings.

## Unsupported ops (static, `unsupported_ops`)

| Op | Why |
|---|---|
| `seqlevels<-` | no public setter (README: `seqinfo<-` pruning/renaming modes not implemented) |
| `seqlengths<-`, `isCircular<-`, `genome<-` | no setter for one Seqinfo column; only `GRanges.with_seqinfo(Seqinfo)` |

All other `ops.json` ops have an `op_*` method (53 of 57 ops). Per-call `unsupported` also arises when:

- an R argument is not a parameter of the port method (`UnknownArgument`): `use.names` on `ranges`/`mcols`/`trim`,
  `na.last`, `method`, `incomparables`, `nmax`, `by`, `na.rm`, `ignore.mcols`, `recursive`, `new2old`, `pruning.mode`,
  `nthread`, `with.inframe.attrib`, `j`, `drop`, and `ignore.strand`/`with.revmap`/`resolve.empty` where only one class has it;
- the port class lacks the attribute (`IRanges.ranges`, `trim`/`seqinfo` on IRanges, accessors on `Seqinfo`);
- `order` of several keys (the port orders one object); `merge` of more than two objects; atomic-vector operands;
- subscripts whose meaning differs from R: zero/negative/fractional integers (port: Python negatives), NA,
  logical vectors not the length of `x` (port: no recycling); `coverage(width=)` as an unnamed vector;
- inputs the port cannot hold: names containing NA (stored as `""`), DataFrame rownames.

## Translations

| R | port |
|---|---|
| `.` in argument names | `_` (`min.gapwidth` -> `min_gapwidth`); `fromLast` -> `from_last`; `y` -> `other` |
| `c(x, ...)` | `concat(x, ...)` |
| `names<-`, `mcols<-`, `seqinfo<-` | `with_names`, `with_mcols`, `with_seqinfo` |
| `findOverlaps`, `countOverlaps`, `overlapsAny`, `subsetByOverlaps` | `find_overlaps`, `count_overlaps`, `overlaps_any`, `subset_by_overlaps` |
| `seqlengths=` named vector in `GRanges()` / `coverage(width=)` | `{name: value}` dict |
| `...` of `IRanges()` / `GRanges()` | `mcols=` dict of typed `polars.Series` |
| mcols / DataFrame | `polars.DataFrame`; Factor = `pl.Enum(levels)` (0-based physical codes), IntegerList = `pl.List(Int64)` |
| `mcols(x)` with no columns | R `NULL` (port: zero-column frame = no metadata) |
| `[` with positive integer `i` | 0-based array (`i - 1`) |
| Hits | projected with `from`/`to` + 1 |
| `findOverlaps`/`nearest`/`precede`/`follow` with `select != "all"`, `order` | 0-based index array + 1; `NO_MATCH` -> NA |
| `distance` | `NO_MATCH` -> NA (the README documents `-1` as the GRanges "incompatible pair" marker) |
| `reduce`/`disjoin` `revmap` column | list elements + 1 |
| `rank` | unshifted (ranks are not indices) |
| atomic results | `RVector` typed by numpy dtype; `seqlengths`/`isCircular`/`genome` named by seqlevel |
| NA in numeric arguments | NaN in a float array / float scalar (the port rejects NaN) |
| named vector -> `{name: value}` (`seqlengths=`, `coverage(width=)`), also for one name | repeated or NA names are `Unsupported` (a mapping cannot hold them) |
| `seqnames` / `strand` vectors in `GRanges()` | lists, so NA stays distinct from Python `None` (R NULL) |
| `...` columns of `IRanges()` / `GRanges()` | `RVector` or a native `pl.Series` (e.g. a Factor input), named by the argument |
