# Adapter notes: e4 (`ranges_e4`)

Port docs used: experiment README, docstrings and public names in `src/ranges_e4`.
Index base: 0-based.

## Unsupported

| Op / argument | Reason |
|---|---|
| `seqinfo<-`, `seqlevels<-`, `seqlengths<-`, `isCircular<-`, `genome<-` | no public setter; objects are immutable |
| `names<-` on GRanges | only `IRanges.with_names` exists |
| `merge` on anything but Seqinfo, or with extra objects | `Seqinfo.merge(other)` only |
| `seqnames`, `strand`, `ranges`, `trim`, `seqinfo`, ... on IRanges | not in IRanges' API |
| `names`, `start`, ... on non-port values (RVector) | not port objects |
| `[`: missing / NULL / NA / zero / negative / double subscripts, logical recycling, `j`, `drop` | ADR-0004: exclusion subscripts not ported; logical must match length |
| `c`: `ignore.mcols`, `recursive` | `concat(*xs)` only |
| `use.names` on `shift`, `narrow`, `ranges`, `mcols`, `trim`, `gaps`, ... | argument missing in port |
| `na.rm`, `with.revmap` (range), `with.inframe.attrib`, `drop.self`, `drop.redundant`, `nthread`, `drop.nohit.ranges`, `strict.strand`, `na.last`, `method`, `incomparables`, `seqlengths` (GRanges), `fromLast` (unique), `by` (sort) | argument missing in port |
| `ignore.strand` on IRanges ops | IRanges methods lack it |
| `range(..., more objects)` on GRanges | `GRanges.range` takes no extra objects |
| `order` with 0 or >1 keys | `order(decreasing)` orders one object |
| `DataFrame` input with non-null rownames | polars frames carry no row names |
| any argument the port requires but the case omits (`nearest`/`precede`/`follow` subject, `rank` ties.method, ...) | port has no default; R defaults are not filled in |

## Conventions translated

- `a.b` -> `a_b`; `fromLast` -> `from_last`; `subsetByOverlaps(ranges=)` -> `subject`; `merge(y=)` -> `other`.
- 0-based -> 1-based: `Hits` (project), `select != "all"` results, `order`, `revmap` mcols column
  of `range`/`reduce`/`disjoin` results (shifted on the native result), positive integer `[` subscripts (1-based -> 0-based in).
- `coverage(GRanges, width=)`: a named width vector becomes the port's seqname -> width dict; unnamed stays positional.
- NA: RVector with NA -> masked array; masked results -> `null`.
- mcols/DataFrame columns <-> polars series (Factor as `pl.Enum`, IntegerList as `List(Int64)`).
- `seqlengths`/`isCircular`/`genome` dicts -> named RVector; `seqnames`/`strand` arrays -> chr RVector.
- `mcols(x)` with no columns projects as a 0-row, 0-column DataFrame: the port's "no mcols" is an empty
  frame of height 0 and does not carry the object length.
