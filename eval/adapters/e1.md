# e1 adapter notes

Port: `ranges_e1` (frozen `frozen/e1-differential`). Docs used: its README and public docstrings.
Port index base: **0-based** for positional results (Hits, `order`, `nearest`/`precede`/`follow`,
`select=`, `revmap`); coordinates are 1-based like R.

## Unsupported

| Op / form | Reason |
|---|---|
| `seqlevels<-` | README: not implemented |
| `order(x, y, ...)` (≠ 1 key) | README: multi-argument `order` not implemented |
| `[` with negative / zero / NA integer, name, NULL, missing `i`, recycled or NA logical subscript | port subscripts are Python-style (negatives wrap, 0 is an index); name / recycling semantics are undocumented in the README |
| `[` with `j`, `drop` | no such argument |
| `c(ignore.mcols=, recursive=)`, `range(na.rm=, with.revmap=)`, `reduce(with.inframe.attrib=)`, `seqinfo<-(new2old=, pruning.mode=)`, `ranges(use.names=, use.mcols=)`, `mcols(use.names=)`, `findOverlaps/countOverlaps(nthread=)`, `coverage(method=)`, `order/sort/rank(na.last=, method=, by=)`, `duplicated/unique(incomparables=, nmax=, method=)` | argument absent from the port |
| any `x` of a class that lacks the method (e.g. `strand(IRanges)`, `seqlengths<-(Seqinfo)`, `trim(IRanges)`) or an R argument the class's method lacks (e.g. `ignore.strand` on IRanges) | `Unsupported` / `UnknownArgument`, decided from the port object's public attributes and signature |
| `DataFrame` inputs with row names, or zero columns with `nrow > 0` | polars frames cannot hold them |
| `mcols` with duplicate column names | polars frames cannot hold them |

## Convention translations

- `a.b` → `a_b`; generics → snake_case methods; `isCircular` → `is_circular`; `fromLast` → `from_last`;
  `subsetByOverlaps(ranges=)` → `subject`.
- Length-1 non-NA R vectors → Python scalars (the port's `mcols`-column-name arguments need a `str`);
  other vectors → ndarray, masked when they hold NA. `names` always an array.
- `+1` on index-valued results: `Hits`, integer results of `findOverlaps`/`nearest`/`precede`/`follow`
  (masked array, not the all-NA logical one), `order`, and the `revmap` mcols column of
  `reduce`/`disjoin` when `with.revmap = TRUE` (two public calls, `mcols` + `set_mcols`).
- `[` positive integers → `-1`; full-length logical passed as is.
- mcols: `(name, column)` pairs ↔ `polars.DataFrame`; Factor ↔ `pl.Enum`; IntegerList ↔ `pl.List(Int64)`;
  extra named constructor args become columns.
- Named vectors: `seqlengths`/`isCircular`/`genome` results (port: dict by seqlevel, or tuple on `Seqinfo`) →
  named R vector; named `value` of the setters → dict.
- `merge` → `Seqinfo.merge_all([x, y, ...])`; `length` → `len`.
- `coverage`: `Rle` → Rle, `dict[str, Rle]` → RleList. No run normalisation beyond the base helper.
