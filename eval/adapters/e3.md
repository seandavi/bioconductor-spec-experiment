# e3 adapter notes

Port: `ranges_e3` (frozen `e3-spec-adr`). Index base: **0-based** elements, 1-based closed coordinates.

## Unsupported

| What | Why |
|---|---|
| ops `seqinfo<-`, `seqlevels<-`, `seqlengths<-`, `isCircular<-`, `genome<-` | no public setter on `GRanges` / `Seqinfo` |
| `findOverlaps(query)` without `subject` | `find_overlaps` requires `subject` |
| `range(x, y, ...)`, `order(x, y, ...)`, `merge(x, y, z, ...)` | extra objects: port takes one (`merge`: two) |
| `ranges(<IRanges>)` | `IRanges` has no `ranges` |
| args `use.names`, `weight`, `method`, `na.rm`, `na.last`, `by`, `incomparables`, `nthread`, `drop.self`, `drop.redundant`, `drop.nohit.ranges`, `strict.strand`, `with.inframe.attrib`, `seqlengths` (GRanges ctor), `ignore.mcols`, `recursive`, `pruning.mode`, `new2old`, `j`, `drop` | port method has no such parameter (`_invoke` raises `UnknownArgument`) |
| `with.revmap` on `range`; `ignore.strand` / `fromLast` on methods that lack them | same |
| `resize(fix=)` as a per-range vector; `GRanges(seqnames=<factor>)` | port takes one string / strings |
| `[` with negative, zero or NA integers, NA names, or a logical mask not of full length | port documents Python negative indexing and refuses short masks (CORE.9) |
| required port argument absent from the R call (e.g. `shift(x)`) | the port has no R default; none is filled in |
| inputs: DataFrame with rownames or rows but no columns; duplicate mcols names; IntegerList names | polars frame cannot hold them |

## Convention translations

- Names: `a.b` → `a_b`; `maxgap`/`minoverlap` → `max_gap`/`min_overlap`; `fromLast` → `from_last`; `subsetByOverlaps(ranges=)` → `subject`; `isCircular` → `is_circular`.
- Generics → methods on the first operand; `c` → `concat`.
- Index-valued results (`order`; `select != "all"` results of overlaps / nearest / precede / follow) get +1 and are returned as R-valued `RVector`. `Hits` get +1 in `project`.
- Positive integer subscripts get −1.
- `revmap`: a list mcols column named `revmap` is 0-based in the port; shifted −1 on input, +1 on projection.
- mcols: atomic columns → typed polars Series (NA → null); Factor → `pl.Enum`; IntegerList → `List(Int64)`.
- `seqlengths` / `isCircular` / `genome` results are named by seqlevels (R returns named vectors); `seqlevels` is unnamed.
- `mcols(x)` with no columns projects as a 0 x 0 DataFrame (the port's empty frame); not corrected.
