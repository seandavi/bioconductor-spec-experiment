# e2 adapter notes

Port: `ranges_e2` (frozen e2-conformance). Index base 0 (Hits, select results, `order`); `NA_INDEX = -1` is "no hit".
Docs used: the port README ("Python API") and the docstrings / public names in `src/ranges_e2`.

## Unsupported

No op is wholly unsupported (all ops have an `op_*`); these forms raise `Unsupported` / `UnknownArgument`.

| Form | Why |
|---|---|
| `use.names` (shift, narrow, flank, promoters, ranges, mcols, trim), `use.mcols`, `na.rm`, `na.last`, `method`, `incomparables`, `nmax`, `with.inframe.attrib`, `with.revmap` on `range`, `strict.strand`, `ignore.mcols`, `recursive`, `drop.self`, `drop.redundant`, `nthread`, `pruning.mode`, `new2old` | port has no such parameter |
| `drop.nohit.ranges` on IRanges, `resolve.empty` on GRanges, `ignore.strand` on IRanges | the class lacks it |
| findOverlaps / countOverlaps / overlapsAny / subsetByOverlaps without `subject` | port requires a subject (no self overlaps) |
| `range` of several GRanges, `order` of several keys, `merge` of more than two Seqinfo | port methods take one |
| `[` with `j` / `drop`; negative, zero, NA, NULL, double subscripts; logical subscripts whose length is not `length(x)` | port documents numpy semantics (negatives count from the end, no recycling) |
| `seqlengths<-` / `isCircular<-` / `genome<-` with a named value | R matches names to seqlevels; the port is positional |
| `GRanges(seqlengths=)` unnamed non-NULL | port takes a `{seqlevel: length}` mapping |
| `seqnames`, `strand`, `seqinfo`, `trim`, `seqinfo<-` ... on IRanges; `ranges` on IRanges; IntegerList inputs; `[` on Seqinfo with non-character subscripts | port has no such method / class |
| duplicated names in a named `seqlengths` / `gaps` bound / `coverage` width | the port takes a `{seqlevel: value}` mapping, which would silently drop entries |

## Conventions translated

- `[`: positive integer subscripts shifted by -1; logical masks and names passed as-is.
- Index-valued results (`findOverlaps`/`nearest`/`precede`/`follow` Hits and select vectors, `order`) get +1; `NA_INDEX` -> NA for select vectors and GRanges `distance`.
- Length-1 R vectors become Python scalars, other lengths lists (NA = `None`); defaults are never filled in.
- mcols: polars DataFrame (int -> Int32, dbl -> Float64, chr -> String, lgl -> Boolean, Factor -> Enum, IntegerList -> List(Int32)). `mcols(x)` and DataFrame inputs are wrapped with `nrow` because the port's column-less frame has no row count.
- Any list column named `revmap` is index-valued (port: 0-based): inputs are built with shift -1, projection adds +1. Symmetric, so user metadata named `revmap` round-trips; provenance tracking was rejected (the port never reads list-column values, and nested calls would lose a marker).
- Coverage weights keep their R storage type (dbl -> float64, int -> int64). `seqlengths` / `isCircular` / `genome` results carry seqlevel names; `length(DataFrame)` is the column count.
- `seqnames()` / `strand()` return an `Rle` of a `Factor`; projected as an expanded chr vector.
- `GRanges.coverage` returns `{seqlevel: Rle}` -> `RleList`; a chr `weight` is the port's mcols column name.
- `gaps` / `coverage` `start`/`end`/`width` named vectors on GRanges become `{seqlevel: value}` mappings (documented port form).
- `seqlevels<-`/`seqlengths<-`/... on Seqinfo use `rename_levels` / `with_field`; on GRanges `with_seqlevels` etc.
